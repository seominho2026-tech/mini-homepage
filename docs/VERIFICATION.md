# 배포 검사 기록

검사일: 2026-09-30

## 확인한 항목

- npm run build 및 TypeScript 검사 통과
- PC 및 모바일 390px 화면 확인, 가로 넘침 없음
- 사진첩 5장 모두 로드, 게시판 및 파도타기 링크 확인
- 공개 사이트 HTTP 200 및 GitHub Pages 배포 성공
- 공개 사이트에서 방명록 작성 후 새로고침해도 유지됨
- 방문 수가 새로고침 시 증가함
- 서로 다른 방문자의 읽기 확인, 본인과 타인의 글 수정/삭제 차단
- 긴 이름, 추가 필드, 비공개 경로 접근, 방문 수 임의 변경 차단
- 검사에 사용한 임시 글은 정리함
- 음악 플레이어가 준비되기 전 입장하는 오류 수정

## 도름스체크 v0.3.1

detect, init, scan을 실행했습니다. 처음에는 Node의 인증서 인식 문제로 SELF_SIGNED_CERT_IN_CHAIN 오류가 났습니다. 인증서 검증을 끄지 않고 NODE_OPTIONS=--use-system-ca로 Windows의 신뢰된 인증서를 적용한 뒤 다시 검사했습니다.

최종 확인: HTTP 200, eligible, blockingFails 없음. 비공개 인증정보 노출 및 위험 코드 패턴 미검출.

권고 사항: CSP 등 일부 보안 헤더, 이용약관 및 canonical 링크. 미확인 사항: 세부 TLS 버전과 도구가 직접 검사하지 못한 DB 접근 권한. DB 권한은 위의 실제 Firebase SDK 검사로 별도 확인했습니다. GitHub Pages는 정적 사이트이므로 앱 서버 런타임 로그가 없고 GitHub Actions 빌드/배포 로그와 브라우저에서 확인했습니다.

이 검사는 전체 보안을 보증하지 않습니다. 방명록은 공개 작성 방식이며 자동 도배 방지나 관리자 화면은 포함하지 않습니다.
