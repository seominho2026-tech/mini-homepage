# 누구나 글쓰기

## 화면과 저장

탭 순서는 홈, 게시판, 방명록, 사진첩입니다. 세 공간에서 로그인 없이 이름을 적고 글을 남길 수 있습니다. 기존 성모찹 링크, 사진 5장, 방명록 글은 그대로 유지합니다.

- 게시판: 이름 20자, 제목 80자, 본문 3000자, 선택 HTTPS 링크.
- 방명록: 이름 20자, 내용 100자. 홈의 기존 한줄평과 같은 DB를 사용합니다.
- 사진첩: 이름, 제목, 사진, 선택 설명. JPG/PNG/WEBP 15MB 이하를 고를 수 있고 브라우저에서 JPEG로 축소해 저장합니다.
- 공개 게시물은 누구나 읽고 새로 작성할 수 있지만 방문자는 기존 글을 수정하거나 삭제할 수 없습니다.
- 저장 경로는 Firestore의 boardEntries, guestbook, photoEntries입니다. 사진은 크기를 제한해 Firestore에 저장하므로 유료 Storage를 새로 연결하지 않았습니다.

## 운영과 복원

변경 전 운영 규칙과 방명록·방문 수를 Git에서 제외한 로컬 .cache/backups 폴더에 보관했습니다. 최신 백업 위치는 .cache/latest-backup.txt에 있습니다. firebase.rollback.json과 firestore.rules로 이전 권한을 복원할 수 있습니다. 복원 시 신규 글을 지우지 않으며 이전 규칙에서는 신규 컬렉션이 비공개로 돌아갑니다.

삭제나 관리가 필요하면 프로젝트 minho-school-lab-20260930의 Firebase 콘솔을 사용합니다. 공개 익명 작성 기능이므로 자동 도배나 작성자 사칭을 완전히 방지하는 기능은 아닙니다. 개인정보를 글에 적지 않도록 안내하고 불필요한 글은 관리자가 정리할 수 있습니다.

## 검사

실제 DB에서 익명 작성·다른 방문자의 읽기, 기존 글 수정/삭제 차단, 허용되지 않은 필드·스크립트 링크·잘못된 사진 형식·크기 초과 차단을 확인합니다. 보안 규칙은 필요한 필드와 길이, 서버 시간을 검사하는 기본 규칙이며 모든 공격에 대한 보장을 뜻하지 않습니다. 공개 전에 실제 동작과 권한 검사를 함께 수행합니다.
